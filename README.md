# Tabular ML Research Agent

Личный портфолио-проект [Рузеля / Ruzik707](https://github.com/Ruzik707) на основе командного решения Альфа Хакатона: агент для автоматического исследования табличных задач машинного обучения.

Агент читает описание задачи и CSV, строит валидацию, обучает модели, проверяет гипотезы и сохраняет `submission.csv`. LLM предлагает изменения, а Python-host независимо вычисляет метрики и управляет временем, ресурсами и выбором модели.

## Возможности

- Регрессия и бинарная/многоклассовая классификация с одним target.
- LightGBM, CatBoost, XGBoost, ExtraTrees и линейные модели.
- OOF, временная валидация и группировка одинаковых строк признаков.
- Валидированные рецепты признаков и моделей, локальный поиск и LLM-исследователь.
- Резервный прогноз, контроль workers, журнал экспериментов и финальное дообучение.
- Проверка сохранённых результатов и воспроизводимая упаковка решения.

## Быстрый старт

Python 3.12. Команды выполняются из корня репозитория.

```bash
uv venv --python 3.12 .venv
uv pip install --python .venv/bin/python -r universal_agent/requirements-mvp.txt

.venv/bin/python universal_agent/solution.py /path/to/task.md --offline \
  --cv-folds 2 --family-trials 1 --max-trials 1 --n-jobs 1 \
  --time-budget 60 --trial-timeout 30 --run-dir runs/smoke
```

Рядом с `task.md` нужны `train.csv` и `test.csv`; также поддерживаются `data_dictionary.csv` и `sample_submission.csv`. Датасеты в репозиторий не включены.

Для исследования с LLM доступны локальная Ollama и OpenAI-compatible endpoint. Без `--offline` и настроенного внешнего endpoint агент ожидает локальную Ollama с `qwen3.5:9b`; модель устанавливается отдельно. Подробности настройки и запуска — в [документации агента](universal_agent/README.md).

## Результаты и ограничения

Сохранённые измерения и условия сравнения доступны в [отчёте внешнего benchmark](universal_agent/docs/AGENT_COMPARISON.md) и [отчёте проверок](universal_agent/docs/VALIDATION.md). Это исторические командные результаты, а не новые измерения этой портфолио-версии.

Агент — исследовательский прототип. Он не лидирует на всех задачах; выигрыш LLM относительно локального поиска требует отдельной проверки. Скрытые оценки хакатона недоступны, полный трёхчасовой soak и Docker для этой поставки не подтверждены. Поддержка single-target CSV не означает поддержку любых задач ML.
